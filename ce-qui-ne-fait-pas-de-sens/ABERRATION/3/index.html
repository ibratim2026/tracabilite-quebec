Ce qui ne fait pas de sens

Des signaux détectés par des règles objectives dans les données ouvertes du SEAO. Un signal n'est pas une accusation : chaque situation peut avoir une explication légitime. Ce que cette page dit, c'est : « voici ce qui, dans les données publiques, mérite une explication ». Et, dans le dernier onglet, ce qui a coûté moins cher que prévu.

Donnée aberrante — comment lire ce signal : Le ratio entre la dépense finale et le montant octroyé est invraisemblable (plus de 20×). Dans la quasi-totalité des cas, il s'agit d'une erreur de saisie dans les données sources du SEAO. Nous le signalons comme un problème de qualité de données, pas comme un dépassement réel.

Règles de détection et limites des données : voir la méthodologie. Les données du SEAO sont déclaratives et peuvent contenir des erreurs de saisie. Un contrat signalé ici n'est ni illégal ni frauduleux : c'est un contrat dont les chiffres méritent une explication.

Traçabilité Québec — un outil d'intelligence citoyenne. Posture éditoriale : pro-transparence, anti-complot. Un signal n'est pas une accusation; chaque écart mérite une explication avant une interprétation.

Source des données : Système électronique d'appel d'offres (SEAO), données ouvertes — Données Québec, diffusées par le Secrétariat du Conseil du trésor. Les données sources peuvent contenir des erreurs de saisie; voir la méthodologie.
